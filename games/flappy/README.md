# Flappy Bird

This locally hosted game adapts the JavaScript canvas implementation by Mario Souto: https://github.com/omariosouto/flappy-bird-devsoutinho. Its MIT license is included in `LICENSE.md`.

The background, ground, rocks, and ready/game-over artwork come from Kenney's Tappy Plane pack and are licensed CC0; the license is included in `assets/CC0-LICENSE.txt`. The bird is drawn in `game.js`; no original Flappy Bird artwork or audio is included.

The game is static and runs from `index.html` with its neighboring JavaScript and assets. No external runtime or build tool is required.
